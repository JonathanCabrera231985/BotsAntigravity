# Guía de Diseño y Estructura
 
## Tech Stack (Confirmado)
- **Lenguaje**: Python
- **Librerías principales**: `gspread`, `oauth2client` (interacción con Google Sheets/APIs).

## Estilo del Reporte en Google Sheets
- **Título**: Fuente Arial/Verdana 14px, Negrita, Color Azul Marino Corporativo.
- **Subtítulos**: Fuente 12px, Negrita, Fondo Celeste Claro (`#E6ECF6`).
- **Tablas de Datos**:
  - Cabecera: Fondo Azul Marino Oscuro (`#1a3366`), Texto Blanco, Negrita, Centrado.
  - Filas: Alineación Izquierda, Ajuste de Texto automático (`WRAP`).
- **Código Fuente**: Fuente de Ancho Fijo (`Courier New`) para bloques de código para legibilidad.
- **Listas**: Indentación visual para listas en columnas.
